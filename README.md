## 0.5.0 录音工作台与独立歌手屏

- 默认录音页保留歌词、进度和常用入口；歌词编辑、时间校准、阅读样式按需打开。
- 独立窗与手机可选单行 / 当前＋下一句 / 上下文三行，并独立调整字号、恢复共享默认。
- 纯歌词隐藏全部功能与状态，点击歌词或 Esc 恢复；独立窗支持 F11 全屏。
- 关闭主编辑窗口不影响独立窗与手机；删除插件或关闭工程仍会停止同步。
- 宿主模式进度只读，由 Cubase 控制；本地预览可播放、拖动，软件不播放伴奏音频。
- 同一歌曲版本只需准备一次时间并保存，无需每遍录音重新分析人声。


Windows 10/11 x64 的 VST3 提词插件与独立文稿工作台。歌词根据宿主工程时间同步，支持 LRC、KRC、QRC、YRC 与 TXT；不进行实时语音识别。

## 0.4.1 手机扫码投屏

设置中开启投屏即可显示本地生成的二维码；手机与电脑连接同一网络，用相机扫码后在浏览器打开。可切换网卡地址、复制当前地址。转动手机自动适配横竖屏，保留字号调节和纯歌词模式；横竖屏保留所选排版。停止投屏会清除二维码，重新开启需要重新扫码。

一版伴奏的歌词时间制作一次即可保存反复使用，不需要每次录音重新分析人声。

## 0.4 自动 KTV 对齐

选择参考人声音频和与该版本一致的实际演唱歌词，由本地模型生成逐字时间，核对预览后点击“应用逐字时间”。应用前原文稿不变；取消不会写入结果。导入已标时歌词后，在插件中使用“跟随宿主”，将歌曲起点设为伴奏的工程起点。播放时，阅读区根据字词的开始和结束时间连续扫色。

参考人声必须与伴奏的速度、剪辑和前奏一致；仅有伴奏不能可靠提供演唱时间。歌词必须逐句对应实际演唱，包括重复段落。界面会预先过滤标题和段落标记，开始前请检查。歌词与音频不匹配时可能被拒绝，模型不会自动改正歌词或保证错误输入仍然准确。模型返回的多字符词块会按比例拆分时间，并给出提示；这些字的边界是近似值，需要听音核对。

首次使用，在发行目录运行 `./setup-alignment.ps1`（源码目录运行 `./scripts/setup-alignment.ps1`）。安装过程联网下载 Python 和依赖，首次对齐还会下载所选模型；模型缓存后在本机处理，音频不上传，原音频文件不修改。发行包只包含安装脚本和 `engine/align.py`，不包含运行环境、模型或用户歌曲输出。配置位于 `%APPDATA%/AmuMusic/CueFlow/alignment.json`。

small 为推荐模型，base 更快；两者首次使用分别下载。完整逐字时间请保存 `.cueflow`；导出 LRC 只保留逐行时间，会丢失逐字时间。引擎与模型保存在本机，发行包不包含用户歌曲。

## 歌曲起点、投屏与 Cubase 实操

新增歌曲起点、局域网浏览器投屏、逐行歌手标签和颜色。详见 Source/docs/CUBASE-QUICKSTART.md（源码目录为 docs/CUBASE-QUICKSTART.md）。TXT需要先逐句打点；单纯切换“跟随宿主”不会识别歌词对应的演唱时间。歌曲起点和整体微调分别保存。

设置 → 开启投屏，使用同一局域网的手机/平板浏览器打开列出的LAN地址。连接 Lyra MIDI 回控后可点击歌词定位；只传歌词和时间、不传音频。停止投屏会撤销链接，重开工程不会自动开启。已有插件请关闭宿主后使用 update-vst3.ps1 更新现有路径，避免安装两份。

视频观察和实现范围见 docs/VIDEO-0.3.0.md。本版颜色/歌手标注按行设置，不含视频中的文字片段颜色编辑；投屏不支持文章滚动。

## 快速开始

打开发布目录中的 CueFlow.exe。将 samples 中的“录音演示.yrc”拖入窗口，选择“时间轴预览”，点击“开始”。这是原创演示文稿，不附带音乐。

在 Cubase、Nuendo 或 Studio One 中使用时，将完整 CueFlow.vst3 文件夹复制到 `%LOCALAPPDATA%\Programs\Common\VST3`，或运行安装脚本。部分宿主需要把此路径加入 VST3 扫描路径。重新扫描插件后，在持续处理音频的轨道上插入 CueFlow，并选择“跟随宿主”。不要只复制包内的 DLL。宿主停止处理或旁路/挂起轨道时，时间可能不再更新，界面会显示等待状态。

宿主兼容性须以实际版本验收为准；自动插件验证和模拟播放头测试不能替代三款工作站的真实录音测试。

## 三种模式

- 跟随宿主：读取宿主工程时间，不控制宿主的播放按钮。循环、回跳与暂停按宿主位置重新定位。
- 时间轴预览：独立时间轴，可播放、暂停、拖动和回到开头。跟随宿主时，歌词定位需要对应宿主回控适配；目前提供 Cubase / Nuendo MIDI Remote 适配，配置见 LYRIC-SEEK.md。
- 文章滚动：普通文稿按设置速度滚动，支持上一页、下一页及鼠标滚轮。聚焦阅读区后，空格暂停，Home 回到开头，Page Up/Down 翻页。

## 导入和校准

可以拖入或选择歌词、TXT 或 .cueflow 项目。KRC 支持 krc1 压缩容器；QRC 支持本地容器、云端十六进制、XML 与明文内容，也识别容器中的逐行翻译。未识别或校验失败的文件会显示错误并保留原文稿。

普通 LRC 只提供逐行时间。逐字扫色需要文件中的字词时间、手动逐字打点，或通过参考人声完成自动对齐；扫色在字词时间段内连续推进。

“整体延后”正数表示更晚出现，负数表示提前。LRC 文件的 `[offset:]` 按其提前补偿语义转换。左侧选择一行后可修改文字及开始秒数；修改文字会移除该行过期的字词时间。Shift 选择连续范围，可以输入平移秒数和时间比例进行校准；比例以所选范围首句起点为锚点。操作可撤销和重做。

逐句、逐字打点使用当前宿主时间或预览时间；请先播放并选中待标注的句子。逐字打点每次记录一个字符的开始，最后多按一次记录结束。未完成的一句中，尚未打点的尾部暂作待标注片段；请完成整句再用于正式录音。尚未打点的其他文章行不会参与时间轴定位。

## 阅读与保存

可调整字号、行距、上下文、对齐和配色。独立阅读窗口可拖到第二块显示器，启用水平镜像后只有阅读文字翻转。F11 进入或退出全屏。

“保存项目”保存完整的文本、字词时间、偏移和阅读设置。插件状态同时随宿主工程保存，不依赖原歌词文件。导出 LRC 仅保留行级时间，字级数据请保存 .cueflow。

独立版退出时会提示保存未保存的修改。它不请求麦克风权限，不录制或播放音频。

## 构建

需要 Visual Studio 2022 C++ 桌面工具链、Windows SDK、CMake 3.22+，以及 JUCE 8.0.12 源码放入 `third_party/JUCE-8.0.12`。发行包 Source/third_party 内附有 JUCE 源码压缩包，解压到同目录即可。CMake 在中文路径下的辅助程序问题已通过构建脚本中的相对路径处理。

```powershell
./scripts/setup-formats.ps1
./scripts/build.ps1
./build/native/CueFlowTests_artefacts/Release/CueFlowTests.exe tests/fixtures
./build/native/CueFlowIntegration_artefacts/Release/CueFlowIntegration.exe research/ui-preview.png
```

测试里的格式样本为原创短句；外部歌词样本仅用于本地互操作验证，不包含在发行包中。
